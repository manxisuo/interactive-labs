教学说明

单色平面波照射两条相距 d、各宽 a 的狭缝后，在距离 L 的屏幕上形成干涉图样。 远场相对强度近似为 I(θ) ∝ [sinc(β)]² · [cos(δ/2)]²， 其中 β = π a sinθ / λ（单缝衍射包络）， δ = π d sinθ / λ（双缝干涉振荡）。

小角度下条纹间距 Δy ≈ λ L / d：波长更长、屏更远、缝更近 → 条纹更疏； 缝宽 a 越大，衍射包络越窄，可见干涉条纹越少。 切换到「单缝衍射」时只保留包络项，中央亮区与两侧暗纹对应衍射极小。

本演示为教学近似：采用远场 Fraunhofer 强度公式 + 俯视波场示意动画，不是完整波动方程求解；屏幕竖直尺度按教学可读性缩放。
